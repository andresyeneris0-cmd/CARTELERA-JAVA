Fundamentos de JavaScript

Variables

Explicación

En JavaScript se usan let para variables que pueden cambiar y const para valores constantes. La diferencia principal es que const no permite reasignación.

Código mostrado

// let y const
let nombre = 'Ana';
const PI = 3.1416;
nombre = 'Luis'; // válido
// PI = 3; // error: reasignación no permitida

Demostración (Guardar mi nombre → mostrarlo → cambiarlo)

Nombre guardado: —

Error frecuente

Declarar variables sin usar let o const (por ejemplo usando variables implícitas) puede crear propiedades globales y causar conflictos.

Operación de asignación

Explicación

Los operadores de asignación combinan operación y asignación:

  • =, +=, -=, *=, /=, %=
  • Incremento/decremento: ++, --

Código mostrado

// contador simple
let contador = 0;
contador += 1;
contador--;

Demostración: contador

0

Error frecuente

Mezclar operadores de asignación en una misma expresión sin paréntesis puede llevar a resultados inesperados.
