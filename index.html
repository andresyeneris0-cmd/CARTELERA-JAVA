Qué es JavaScript

Definición

JavaScript es un lenguaje de programación que permite añadir comportamiento a las páginas web. HTML define el contenido, CSS la apariencia y JavaScript el comportamiento.

Historia

Fue creado por Brendan Eich en Netscape. Originalmente llamado Mocha, luego LiveScript y finalmente JavaScript. El estándar se llama ECMAScript, y versiones como ES6/ES2015 añadieron muchas mejoras.

Resumen (tabla)

Año Evento
1995 Creación por Brendan Eich (Netscape)
2015 ES6 / ES2015 (gran actualización)

¿Dónde se ejecuta?

  • En navegadores (Chrome, Firefox, Edge, Safari).
  • En servidores con Node.js.

Diferencia entre Java y JavaScript

A pesar del nombre, son lenguajes diferentes: Java es tipado estático y orientado a objetos clásico; JavaScript es dinámico y originalmente pensado para manipular el DOM en el navegador.

Código de ejemplo

// Ejemplo: función que saluda
function saludar(nombre) {
  return `Hola, ${nombre}!`;
}
console.log(saludar('Estudiante'));

Botón "Saludar"

Este botón mostrará la fecha y hora exactas al momento de presionarlo.

Error frecuente

Olvidar colocar el script al final o usar un selector que no existe, lo que provoca errores en la consola.
