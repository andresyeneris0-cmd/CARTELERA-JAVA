Control del flujo en JavaScript

Condicionales

Explicación

Las estructuras condicionales permiten ejecutar código según condiciones: if, else if, else y switch. Los operadores de comparación incluyen ===, !==, >, <, etc. Los operadores lógicos son &&, ||, y !.

Código

// if/else example
const nota = 4.2;
if (nota >= 4.5) {
  console.log('Superior');
} else if (nota >= 4.0) {
  console.log('Alto');
} else if (nota >= 3.0) {
  console.log('Básico');
} else {
  console.log('Bajo');
}

Demostración: clasificador de notas (0–5)

Error frecuente

No validar la entrada del usuario (por ejemplo usar NaN o valores fuera de rango) produce resultados incorrectos o errores.

Ciclos

Explicación

Los bucles permiten repetir acciones: for, while, do...while y for...of. Use break y continue para controlar el flujo.

Código

// for: tabla de multiplicar
for (let i = 1; i <= 10; i++) {
  console.log(`${n} x ${i} = ${n * i}`);
}

// for...of: iterar caracteres
for (const c of 'hola') {
  console.log(c);
}
