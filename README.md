## Descripción

Sitio educativo que explica conceptos básicos de JavaScript y ofrece
ejemplos interactivos y demostraciones para aprender: variables, tipos de
datos, asignación, condicionales y ciclos. Está diseñado para ser usado en
entornos de práctica y para publicarse en GitHub Pages.

## Estructura del proyecto

- `index.html` — Portada y Tema 1 (Qué es JavaScript)
- `fundamentos.html` — Variables, Datos y tipos, Asignación (demos ejecutables)
- `control.html` — Condicionales y Ciclos (demos ejecutables)
- `css/estilos.css` — Estilos centrales y variables de color
- `js/script.js` — Lógica compartida y demos JavaScript

## Cómo ejecutar

1. Abrir `index.html` en un navegador moderno.
2. Navegar entre las páginas usando el menú.

Para publicar en GitHub Pages, crea un repositorio con este contenido y
activa Pages desde la rama `main` (o `gh-pages`) en la configuración del
repositorio.
